| MQA-01 | Войти временным координатором. Открыть быстрый режим. Передать 9 значений с запятыми с пробелами и без; полный адрес не передавать | Сохранены распознанные значения; запрашивается только полный адрес | До исправления бот запрашивал улицу. FAIL | M01, BR-01 |
| MQA-02 | После исправления повторить неполный ввод из 9 значений | Сохранены данные; запрашивается только полный адрес | Автор прямо подтвердила этот результат. PASS, исторический retest | M02 |

| MQA-04 | Передать полный компактный ввод из 10 значений | Preview сразу, без дополнительных вопросов | Автор подтвердила разбор без вопросов. PASS | M02 |
| MQA-05 | Просмотреть public preview после быстрого ввода | Имя, телефон и полный адрес отсутствуют | Автор подтвердила отсутствие этих полей. PASS только для просмотренных образцов | M02 |

В MQA-06 настройку меняли в ходе исторической работы. При составлении кейса конфигурация и роли не изменялись. Ожидание автоматического отзыва требует явной политики; само сохранение приветственного текста не доказывает сохранение полномочий.

## Checklist выполненных действий

| Проверка | Исторический результат | Основание |
| --- | --- | --- |
| Неполный ввод из 9 значений | FAIL → PASS после исправления | MQA-01/02 |
| Дозаполнение только отсутствующего адреса | PASS | MQA-02/03 |
| Полный ввод из 10 значений | PASS | MQA-04 |
| Отсутствие имени, телефона, полного адреса в preview | PASS с ограничением образца | MQA-05 |
| Роль тестового аккаунта после смены coordinator ID | FAIL наблюдения; ручной retest отсутствует | MQA-06 |

Эти строки группируют те же действия, а не добавляют новые прогоны. Успешных исторических сценариев — четыре строки MQA-02–05; исходных проблемных наблюдений — две строки MQA-01/06. Они не являются шестью независимыми тестовыми сессиями.

## Покрытие без подтверждения ручного выполнения

| Область из найденных требований | Статус | Недостающее доказательство |
| --- | --- | --- |
| Карточка реально появилась в канале после исправления прав | NOT RUN / evidence pending | Сообщение автора или обезличенный скрин канала после повторной публикации |
| Одновременное принятие двумя исполнителями, ровно один победитель | NOT RUN | Протокол двух тестовых аккаунтов и состояния назначения |
| Полные данные получает только назначенный исполнитель | NOT RUN | Обезличенные результаты обоих тестовых аккаунтов |
| Финансы, завершение, повторное завершение | NOT RUN | Актуальные требования и ручные expected/actual |
| Отказ клиента, возврат, повторная публикация | NOT RUN | Полный ручной протокол переходов |
| Ручной отзыв прав и `/pending` в группе после исправления | NOT RUN | Retest в Telegram; offline тесты отдельно |

Успешные mocks или утверждение ассистента «всё работает» не заполняют эти пробелы.
