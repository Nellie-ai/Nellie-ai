## Отдельный интеграционный инцидент

Автор сообщила об отказе публикации карточки с текстом «Telegram не принял карточку. Черновик сохранён, попробуйте снова». В историческом read-only отчёте агента Telegram API вернул `403 Forbidden: bot is not a member of the channel chat`. Это подтверждённая проблема конфигурации доступа к каналу, а не установленный дефект отправляющего кода.

Самостоятельное успешное повторение после настройки прав в доступных первичных материалах не подтверждено: NOT RUN / evidence pending. Сохранение черновика описано в отчёте агента по порядку операций; отдельного ручного доказательства состояния БД нет. ID канала, username бота и данные заявки исключены.

## Достоверность результатов AI-агента

Отчёты агента проверяются по доступным протоколам до/после исправления, исполнителям, среде и ограничениям. Ручной retest автора (M02) не смешивается с изолированными агентскими тестами. Production-проверка и полный независимый аудит всех правок агента не заявляются.

## AI safety: применимость

AI/LLM в найденном scope не подтверждён. Историческая задача явно требовала детерминированный parser без LLM/API. Нельзя заявлять тестирование медицинских ответов модели, hallucinations, prompt injection, отказов LLM или безопасных дозировок. Все такие проверки — NOT RUN, функция для проверки не установлена.

Подтверждённые safety-проверки этого кейса относятся к приватности preview и контролю доступа. Медицинская безопасность ответов не проверялась. При появлении отдельной AI-функции понадобятся её требования, версия модели и отдельный набор согласованных критериев; в текущем PR такой функциональности не добавляется.

## Недостающие доказательства

Точная сборка и Telegram-клиент ручного smoke; обезличенные скриншоты до/после; ручной retest ролей; успешная публикация и полный цикл; актуальное финансовое правило; данные согласованного тестового контура для повторения. Отсутствие этих свидетельств оставлено видимым.
