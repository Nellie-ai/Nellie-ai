# Практикум: основа Manual QA case study

Учебный кейс веб-приложения «Самокат» и тест-дизайна Android-приложения. Подготовлен 03.11.2026 из найденного локального workbook `финал20.xlsx` и истории дипломного ревью. Это отдельный проект, не VetHelp911 и не автоматизированные дипломные репозитории `Diplom_1/2/3`.

## Проверенные материалы

Найден и прочитан workbook с пятью листами: «Задание 1 чек-лист», «Задание 1 данные валидации», «Задание 1 баги вне тестовой док», «Задание 2 тест-кейсы», «Баг-репорты». SHA-256 оригинала и агрегаты сохранены в [workbook-summary.json](evidence/workbook-summary.json). Содержимое оригинального workbook не публикуется.

В истории «Аудит диплома по тестированию» автор указывала `финал20` как актуальную версию. В истории «Ревью диплома QA» автор сообщила о полученном зачёте. Это пользовательское сообщение, а не независимо проверенный сертификат или запись учебной платформы.

Файлы Drive с названием `Diplom_1.pdf` не приняты за QA-источник: просмотренный файл относится к университетскому образованию. Содержимое и персональные реквизиты исключены.

## Роль автора

Nellie-ai — автор найденных учебных материалов и участник ручного тестирования/доработок по истории дипломного ревью. Workbook содержит собственные checklist, классы эквивалентности/границы, баг-репорты и мобильные test cases. Помощь ассистента в редактировании документации не выдаётся за самостоятельное выполнение каждого теста.

## Подтверждённый объём и результаты

Здесь PASS/FAIL — значения, записанные в историческом workbook. Нового выполнения на стенде нет. Табличные PASSED/FAILED нормализованы в PASS/FAIL только в этой сводке.

| Область | Найденный объём | Исторические значения | Новый прогон |
| --- | --- | --- | --- |
| Экран статуса заказа, web | 45 уникальных checklist-сценариев × 2 браузера = 90 status cells | Яндекс.Браузер: 37 PASS / 8 FAIL; Chrome: 36 PASS / 9 FAIL | NOT RUN |
| Валидация формы заказа | 73 заполненные status cells на листе | 61 PASS / 10 FAIL / 2 N/A | NOT RUN |
| Баг-репорты | 24 записи с ID от BUG-001 до BUG-026 с пропусками нумерации | Записанные дефекты; не 26 найденных багов | NOT RUN / не перевоспроизведены |
| Android | 10 cases: N-01/02/03/04/07 и NET-01–05 | Предусловия, шаги, ОР; поля результатов выполнения не найдены | NOT RUN / evidence pending |
| API | В этом workbook отдельный API-лист отсутствует | Результаты из других дипломных проектов не перенесены | NOT RUN |

Не суммировать 90 browser-status cells и 73 validation-status cells как число уникальных сценариев. Общий процент успешности не рассчитывается: единицы учёта различаются.

Окружения записаны в источнике: Windows 11; Яндекс.Браузер 26.6.0.1831, 1920×1080; Chrome 149.0.7827.102, 1280×720. В отдельных BR встречаются другие размеры, их нельзя автоматически заменить значениями checklist. Android cases указывают Android Studio Emulator / Android 9.0; это описание планируемого окружения, не доказательство запуска.

## Структура будущего полного кейса

| Раздел | Основа из найденного источника | Чего пока не хватает |

| Checklist / traceability | WEB-CL-01–45; BUG links; WEB-CL-36 различается по браузерам | Полная проверка целей ссылок и приложенных доказательств |
| Bug reports | Поля ID, приоритет, предусловия, шаги, expected, actual, окружение, вложение | Обезличенные оригиналы screenshot/video и независимое повторение выбранных дефектов |
| Exploratory testing | Лист дефектов вне тестовой документации | Charter и журнал сессии отсутствуют; нельзя приравнивать список дефектов к формальному exploratory run |
| Regression | История правок workbook по ревью | Правка ячейки не доказывает повторный прогон приложения; execution evidence pending |
| Test summary | Записанные статусы и агрегаты выше | Отдельная подтверждённая сводка фактического выполнения |

## Кандидаты для дальнейшего bug dossier

Это найденные записи источника, не новые подтверждённые дефекты. Шаги в таблице сокращены для навигации; полный отчёт создаётся после проверки оригинальных доказательств.

| ID / ячейки источника | Описанные steps | Записанные expected / actual | Состояние evidence |
| --- | --- | --- | --- |
| BUG-008, `Баг-репорты!A9:J9` | Ввести имя с дефисом, снять фокус | Принимается / красная подсветка и ошибка имени | Поле вложения пусто. Независимое подтверждение pending |
| BUG-018, `Баг-репорты!A17:J17` | Отменить заказ | Модальное окно / отдельный белый экран | Указано имя PNG, самого изображения в workbook нет. Chrome связан с FAIL в WEB-CL-36 |
| BUG-021, `Баг-репорты!A20:J20` | DevTools → Network → отменить заказ → открыть запрос | HTTP 2xx / HTTP 400 с сообщением о недостатке данных при UI-успехе | Указан `httperror.png`; файл не найден в проверенных материалах. Запрос не повторялся |

Трек-номера, адреса, имена, логины/пароли и ссылки исходного workbook исключены. В workbook нет встроенных изображений: имя файла вложения не доказывает, что screenshot просмотрен. У BUG-020 в найденной версии нет явной системной даты в предусловиях, поэтому «прошедшая дата» без дополнения не даёт воспроизводимого оракула. Это ограничение исходной записи, не повод менять её в рамках подготовки основы.

## Следующий проверяемый шаг

Выбрать 2–3 BR после получения исходных требований, обезличенных доказательств и build ID; сверить expected/actual; отдельно отметить исторические и новые результаты. Android и API не объявлять выполненными до появления протоколов. Сейчас готова документированная основа, а не полный заново исполненный дипломный QA-кейс.
